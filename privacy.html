3. Какие данные мы обрабатываем

  • Идентификатор устройства (ANDROID_ID) — анонимный технический идентификатор, используемый для привязки статуса подписки и ограничений бесплатного тарифа. Не позволяет идентифицировать личность пользователя.
  • Данные о подписке — дата активации, срок действия премиум-доступа, история платежей. Хранятся в Supabase.
  • Данные об использовании — количество сессий в сутки, дата последнего обращения. Используются для применения ограничений бесплатного тарифа.
  • Сообщения и запросы — текст, отправляемый персонажам Приложения, передаётся в DeepSeek для генерации ответа. Разработчик не хранит содержание переписки на своих серверах. История чата сохраняется только локально на устройстве пользователя.
  • Push-токен устройства — используется Firebase для отправки технических уведомлений о состоянии сервиса. Не связан с личностью пользователя.
  • Аналитические данные — анонимная статистика об открытиях Приложения и использовании функций, собираемая через Яндекс.Метрика AppMetrica. Не содержит персональных данных.
  • Данные при оплате — обрабатываются непосредственно платёжным сервисом Robokassa. Разработчик не получает и не хранит данные банковских карт.

  • Обработка платежей и подтверждение активации подписки.
  • Отправка технических уведомлений о работе сервиса.
  • Анализ агрегированной статистики использования для улучшения Приложения.
  • Техническая поддержка пользователей.
  • Исполнение требований законодательства Российской Федерации.

6. Передача данных третьим лицам

Данные могут передаваться следующим сервисам в объёме, необходимом для работы Приложения:

  • Supabase Inc. (США) — облачное хранение данных об аккаунтах и подписках. Данные передаются с применением шифрования.
  • DeepSeek — сервис генерации ответов на основе ИИ. Получает текст запросов пользователя без привязки к идентификатору личности.
  • Robokassa (ООО «Пэйлэнд») — приём платежей на территории РФ. Обработка платёжных данных регулируется политикой конфиденциальности Robokassa.
  • Google Firebase — сервис push-уведомлений. Получает push-токен устройства.
  • Яндекс.Метрика AppMetrica — анонимная аналитика использования Приложения.
  • Государственные органы РФ — при наличии законного требования, предусмотренного законодательством.

Разработчик не продаёт и не передаёт данные пользователей третьим лицам в коммерческих целях, не связанных с работой Приложения.

7. Трансграничная передача данных

Часть данных обрабатывается серверами, расположенными за пределами Российской Федерации (Supabase, DeepSeek, Firebase). Передача осуществляется с соблюдением требований ст. 12 ФЗ-152, в том числе при наличии надлежащего уровня защиты в стране получателя или на основании согласия субъекта персональных данных.

8. Хранение данных

  • Идентификатор устройства и данные о подписке — хранятся в течение срока действия подписки и 1 года после его окончания.
  • Данные об использовании (счётчики сессий) — автоматически сбрасываются ежесуточно.
  • История переписки — хранится только локально на устройстве, на серверах Разработчика не сохраняется.
  • Аналитические данные — хранятся в агрегированном обезличенном виде.
